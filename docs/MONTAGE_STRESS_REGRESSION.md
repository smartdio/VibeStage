# 走廊与开放平台连续操作回归（2026-11-14）

本轮完成 montage-stress 项目的两套新场景、四组十四镜及四个导演包。通过 ego-browser TaskSpace 26 实际操作工作台，未发现新的状态串改、修改丢失或预览构图回退；没有新增框架代码修改。全部既有未提交修改保留，未提交、推送或发布。

## 场景与操作边界

项目及 corridor、reverse 两个场景由界面创建。新建模板随后改写为私人 Three.js 场景：参考公开 montage 示例，建立宽走廊和开放平台斜墙、两位可移动人物、道具箱以及道歉／等待动作。此时不存在相机设置文件。布景、动作和初始预设由场景代码定义；分镜创建、切点、引用、独立表演与摆位、参数调整、取消／放弃、保存和导出均使用界面。没有通过内部业务 API 或直接 JSON 写入代替被测操作。既有用户项目未修改。

每场主剪辑五镜各2秒：全景、滑动变焦、过肩道歉、后跟、完整环绕；对照剪辑两镜各5秒：同一滑动变焦、跳切站定全景。两场、两组复用相同镜头 ID，故意检验隔离。两场总计十四镜，四组分别交付，不自动拼接。

corridor 主组全景26mm、滑变起始34mm，向前1.4米补偿焦距；reverse 主组全景25mm、滑变起始30mm，向后1.2米补偿焦距。两场对照组均保留原wide28mm和dolly32mm。主组4秒启动独立道歉，A分别位于X=-1／+1、朝向180°／90°；6秒和8秒镜头延续动作。对照组5秒启动站定等待，独立于主组动作与摆位。

## 混合操作结果

两场各执行：播放中打开运镜，明确shared设36mm，点击播放自动应用，另一组同步；取消31mm独立草稿，不生成新机位；重新打开默认shot，播放应用30mm自动独立，另一组仍36；放弃恢复原32mm与原引用。

播放中过肩镜头分割，新增片段继续道歉动作；选回原独立起点并删除，新增片段不再继承道歉；放弃后恢复原五镜，后跟再次继承shot_3的apology动作、来源时间与摆位。没有将删除后失去继承误判为故障。

播放中进入HUD转向再取消，机位不变且无dirty。参数入口shared29mm联动另一组，切镜默认shot改27mm自动独立，放弃恢复。随后分别保存上述最终独立焦距；全景调整在播放中保存，浏览器刷新和跨场景后保持，原对照组32／28不变。共30个结构化检查点见stress-log.json。

另在reverse临时把主组首镜重新指向wide，HUD共用转向应用，另一组四元数相同；另一组默认shot，先转向取消，再转向应用自动独立，原wide姿态不变。放弃恢复主组camera_1及其已保存构图，六个检查点见hud-log.json。此后刷新再进行全部最终播放与导出。

此前数值滚轮保护在十四份资料的连续填写、滚动和保存中未阻碍操作；四组均显示“信息完整”。

## 实际画面调整与自动化说明

reverse过肩初始人物重叠。通过界面设世界方位90°、侧偏1米，形成A肩背右前景、B左后景；A被边缘裁切是明确设计。后跟增加侧偏1.2米。均保存并重新播放、导出检查。

完整环绕预设按方向正负运行一整圈，不按数值幅度运行半圈；早期设计文字的半环绕假设已改正，最终两场分别正向／反向360°，未把预设既有合同误报为故障。

自动化修正不计为产品缺陷：range不能用fill设置，最终精确采样用真实键盘Home／PageUp／ArrowRight；切点改用结束时间输入框并失焦。只渲染当前镜头的删除按钮，删除原独立起点前先选回原镜头。预设打开后等待范围控件渲染；自定义场景默认自由观察，切入后主动选择“拍摄画面”。所有中断均在同一空间恢复，未绕过导航或草稿保护。

## 预览与导演包对照

最终保存刷新后，两轮逐镜回放，最终保留42张首／中／末截图；四组完整顺序播放验证14次自动切镜。另用时间滑杆键盘采集28个精确时刻，加14个镜头实际末帧，共42个样本与导演包比对：cameraId、shotId、位置、四元数、焦距和表演时间／来源一致，数值最大误差0。

四包共960帧（每组10秒、24fps）。逐帧验证机位引用、独立道歉继承及A摆位、等待动作和原始行走轨迹；核验镜头顺序、片段视频帧数、人物／灯光／节拍资料及提示词。source.zip内两场景源码、相机设置、delivery.json与最终保存文件逐字节相同。每镜从导出视频取0／25／50／75%／末帧，四张联系表共70帧已人工查看，构图与运动符合设计。

预览带实时景深及阴影，导演包参考视频按fast-white-model模式不呈现景深、对焦模糊和阴影，分辨率长边640；因此不宣称两者逐像素相同。比对结论是构图、运动、切点与表演数据一致，并已观察实际导出画面。

最终相机、资料、音频未保存标记均false，busy=false，浏览器异常／error日志为空。111/111测试、npm run build、npm run check:projects和git diff --check通过。本轮范围内没有新增未修复状态问题；实体触屏及其他浏览器未覆盖。
