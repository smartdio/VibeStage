# 运镜学习样板 · 32 种镜头

这是运镜学习样板的源代码。内置原版只读，供观看、比较与导出；复制到私人 projects 目录后可自由编辑。第一次打开工作台且没有有效的上次选择时，默认进入本项目。它直接由框架提供，固定列在项目列表顶部，不复制成可编辑的私人原版；更新后仍会显示，不能通过工作台修改或删除。

## 怎样学习

1. 在“拍摄画面”中播放当前镜头，每个镜头独立演示 12 秒。
2. 使用播放按钮两侧的“上一个镜头 / 下一个镜头”，从头观看相邻镜头；播放中切换会继续播放，暂停时停在起点。也可从右侧机位列表直接选择，再拖动时间轴。
3. 查看右侧的用途与观察重点。需要调参练习时，点击左侧“复制为我的项目”，在生成的私人副本中展开“动手练习”。
4. 切换到列表末尾的“布景全景”理解空间，或用“俯视路径”比较机位轨迹。金色为第一批、青色为第二批、紫色为第三批。圆点表示起点，固定机位只有点；辅助路径只出现在专门的俯视机位中。

01–16 为基础镜头：建立、双人、过肩、反应、细节、主观、推进、拉远、摇镜、跟拍、短弧、揭示和拉焦。17–30 为进阶镜头：角度、升降、变焦、手持、完整环绕和主体固定。31–32 为连续交接与穿行俯冲。

建议成对比较：推进与变焦、上下摇镜与垂直升降、短弧与完整环绕、跟拍与主体固定、固定构图与拉焦。观察摄影机位置、朝向和焦距中究竟哪一项发生了变化。

## 原版与副本

内置原版保存在 `examples/camera-school/`，属于框架资源。工作台使用保留 ID `vibestage-camera-school`，服务端拒绝新建场景、机位保存和音频修改；新建场景对话框也不提供该项目。场景代码可阅读，练习副本创建在 `projects/camera-practice/` 或带编号的新目录中，不会覆盖已有项目。

副本是完整的普通 Three.js 项目。`scenes/showroom.ts` 搭建布景、动作和 32 个机位，`shared/lessons.ts` 保存教学内容。Agent 可修改副本，不应为个人练习改动内置原版。首次初始化和后续启动都不会覆盖副本。

“俯视路径”在场景创建时根据代码采样，副本中手动修改预设后不会自动重绘这些参考线；请让 Agent 同步代码并重新加载。甩镜没有运动模糊，路径警告不是自动避障。此样板用于理解运镜，不是完整摄影物理仿真。

原版的导出可包含当前画面、摄影机记录与公共源码快照，不打包私人项目或私人模型；副本导出遵循普通项目的备份规则。
